# جداول الجمع والناقص حتى 20

برنامجان تعليميان بسيطان للأطفال (من عمر خمس سنوات تقريبًا)، يعملان في المتصفّح مباشرة
بلا تثبيت وبلا تسجيل دخول:

- **جداول الجمع والناقص حتى 20** — الصفحة الرئيسية (`index.html`)
- **مغامرة الجمع** — لعبة جمع (`addition-adventure.html`)

## التشغيل

افتح الرابط في متصفّح الجهاز. يعمل البرنامج على الهاتف والتابلت والحاسوب.

## إضافته إلى الشاشة الرئيسية كتطبيق

**iPad / iPhone (Safari):**
1. افتح الرابط في Safari.
2. اضغط زر المشاركة (المربع مع السهم لأعلى).
3. اختر «إضافة إلى الشاشة الرئيسية» (Add to Home Screen).
4. اضغط «إضافة». ستظهر أيقونة البرنامج مع بقية التطبيقات، ويفتح بملء الشاشة.

**Android (Chrome):**
1. افتح الرابط في Chrome.
2. اضغط قائمة النقاط الثلاث أعلى اليمين.
3. اختر «إضافة إلى الشاشة الرئيسية» / «تثبيت التطبيق».

## ملاحظات
