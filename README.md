# برامج الحساب للأطفال

أربعة برامج تعليمية بسيطة للأطفال (من عمر خمس سنوات تقريبًا)، تعمل في المتصفّح
مباشرة بلا تثبيت وبلا تسجيل دخول. الصفحة الرئيسية صفحة بداية تجمعها كلها.

| البرنامج | المسار |
| --- | --- |
| صفحة البداية (تفتح البرامج الأربعة) | `index.html` |
| عالم الحساب للصغار (الصغير: جمع وناقص · الكبير: ضرب وقسمة حتى 100) | `math-world.html` |
| جداول الجمع والناقص حتى 20 | `addition-tables.html` |
| جداول الضرب | `multiplication.html` |
| مغامرة الجمع | `addition-adventure.html` |

## إضافته إلى الشاشة الرئيسية كتطبيق

**iPad / iPhone (Safari):**
1. افتح الرابط في Safari.
2. اضغط زر المشاركة (المربع مع السهم لأعلى).
3. اختر «إضافة إلى الشاشة الرئيسية» (Add to Home Screen).
4. اضغط «إضافة». ستظهر أيقونة واحدة تفتح صفحة البداية بملء الشاشة.

**Android (Chrome):**
1. افتح الرابط في Chrome.
2. اضغط قائمة النقاط الثلاث أعلى اليمين.
3. اختر «إضافة إلى الشاشة الرئيسية» / «تثبيت التطبيق».
